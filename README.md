GitHub Pages · Source = `main` branch / `/docs` folder

| 경로 | 내용 |

## 배포 방법

`push.cmd` 실행 — 변경 파일 커밋 후 `main` 브랜치로 push.

```
push.cmd
push.cmd "커밋 메시지"
```

사전 조건 — Git 설치, GitHub 인증(Git Credential Manager 또는 PAT).
